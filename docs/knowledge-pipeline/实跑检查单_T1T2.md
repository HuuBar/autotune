## 1. T1 live 编译检查单（验收 V1，证据等级 [live]）

```bash
python3 -m knowledge_pipeline.compiler compile \
  --cards docs/knowledge-pipeline/自动化ML优化战术知识卡_v1.md \
  --brief knowledge_pipeline/fixtures/tbox_brief.yaml \
  --out compile_live_out --live
echo "exit=$?"
```

| # | 检查 | 通过标准（=V1） | 失败时看哪里 |
|---|---|---|---|
| 1.1 | 退出码 | `exit=0` | 非 0 → 看 stderr 首行错误类别（端点失败/编译失败/cache 未命中，03 手册 §2 对照表） |
| 1.2 | 产物齐全 | `compile_live_out/` 下 `graph.yaml` + `card_decisions.json` | 缺文件 → stderr 中编译阶段报错，贴回完整 stderr（这是重要数据） |
| 1.3 | graph.yaml 过 M1 校验 | `python3 -c "from knowledge_pipeline.validator import validate_file; print(validate_file('compile_live_out/graph.yaml'))"` 输出 `[]` | 非空 → 图非法：直接进 V6 降级验收反而正好可用它当非法图 |
| 1.4 | card_decisions 覆盖全卡库 | `card_decisions.json` 中决策条数 = 卡库卡片数（24 张），每卡有 select/reject 论证 | 缺卡 → 编译器选卡阶段问题，贴回 card_decisions.json |

> 离线缓存模式（无 dsv4 时的冒烟）：把 `--live` 换成 `--cache`，预期走缓存产物；cache 未命中说明 prompt 已变，属预期，不算失败。[mock]

快速 schema 复核命令：

```bash
python3 - <<'PY'
import json
from knowledge_pipeline.ledger import Ledger
s = json.load(open('log/kg/state.json', encoding='utf-8'))
assert all(k in s for k in ('version','graph_path','nodes','decisions','gain_history','refresh_count')), 'state.json 缺键'
for i, line in enumerate(open('log/kg/hypotheses.jsonl', encoding='utf-8')):
    if line.strip():
        Ledger.validate_record(json.loads(line))
print('V7 schema 复核通过')
PY
```
